# BUG-002: Login Submission Accepts Empty and Incomplete Credentials

**Severity:** High — Authentication bypass allowing unauthenticated access to application without credentials.
**Framework:** Maestro / Appium / XCUITest
**Element Identifier:** `login-email`, `login-password`, `login-error`, `login-submit` (or text: "Log In")
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** No

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Maestro v2.8.0 / pytest 8.4.2 / xcodebuild

### Steps to Reproduce
1. Launch the app fresh on a clean simulator.
2. Observe the Login screen with `login-email` and `login-password` fields blank.
3. Tap the "Log In" button without entering any text.

### Expected Result
Login is rejected. The user remains on the Login screen, an error message "Email and password are required" is displayed via `login-error`, and navigation to the product catalog is blocked.

### Actual Result
No validation error is displayed. The app immediately logs in and navigates to the Product Catalog screen (`product-name-p1`).
