# BUG-015: Bottom Tab Bar Navigation Is Visible and Interactive Prior to Authentication

**Severity:** Medium — Information architecture defect allowing unauthenticated users to see and interact with protected app tabs.
**Framework:** Maestro / Appium / XCUITest
**Element Identifier:** `text: "Products"`, `text: "Cart"`, `id: bag`, `id: cart`
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** No

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Maestro v2.8.0 / pytest 8.4.2 / xcodebuild

### Steps to Reproduce
1. Launch the app fresh on a clean simulator.
2. Do not log in; remain on the initial screen.
3. Observe the bottom navigation bar area.

### Expected Result
The bottom tab bar (Products and Cart tabs) is completely hidden until authentication succeeds. Only the Login screen content is visible.

### Actual Result
The bottom tab bar is fully visible, rendered, and active on the unauthenticated login screen.
