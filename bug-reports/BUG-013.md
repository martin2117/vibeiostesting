# BUG-013: Confirmation Screen Missing Order Reference Identifier

**Severity:** Medium — Audit and order tracking defect leaving customer without an order reference number.
**Framework:** Maestro / Appium / XCUITest
**Element Identifier:** `confirmation-order-ref`, `confirmation-title`
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** No (Is blocked by BUG-011 on broken build)

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken / Fixed (Requires BUG-011 fix to reach checkout screen)
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Maestro v2.8.0 / pytest 8.4.2 / xcodebuild

### Steps to Reproduce
*(Note: Because BUG-011 makes 'Proceed to Checkout' a no-op on the initial broken build, test with BUG-011 fix applied or by navigating directly to the Checkout screen).*

1. Launch the app fresh on a clean simulator.
2. Log in with `demo@techshop.com` / `password123`.
3. Add Product 1 ($60) to cart (`add-p1`) and navigate to Checkout screen.
4. Fill valid customer details:
   - First Name: `Jane`
   - Last Name: `Doe`
   - Email: `jane.doe@example.com`
   - Phone: `1234567890`
   - Card Number: `1111222233334444`
   - Expiry: `12/29`
   - CVV: `123`
5. Tap "Place Order" (`checkout-submit`).
6. Inspect the Confirmation screen.

### Expected Result
Confirmation screen displays "Order Confirmed" along with a unique generated order reference string (e.g., "Order Reference: TS-481920") mapped to element identifier `confirmation-order-ref`.

### Actual Result
The confirmation screen displays the title and total, but completely omits the `confirmation-order-ref` element and order reference ID.
