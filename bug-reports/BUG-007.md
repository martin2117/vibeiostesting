# BUG-007: Product Catalog Long Title Overflows Cell Height Bounds

**Severity:** Low — Visual layout and UI clipping defect disrupting catalog presentation.
**Framework:** Appium / XCUITest (Maestro cannot assert bounding box geometry)
**Element Identifier:** `product-name-p3`
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** No

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Appium Python Client (pytest 8.4.2) / Xcode 16 xcodebuild

### Steps to Reproduce
1. Launch the app fresh on a clean simulator.
2. Log in with `demo@techshop.com` / `password123`.
3. On the Product Catalog screen, scroll to Product 3: "Ultra-Wide Curved 49-inch Professional Gaming Monitor with HDR".
4. Inspect the cell height, bounding frame, and typography layout of `product-name-p3`.

### Expected Result
The long title is truncated cleanly with an ellipsis (`.lineLimit(1)` / `numberOfLines={1}`), keeping the list row within standard compact height constraints (~20–40px).

### Actual Result
The title wraps into multiple unconstrained lines, expanding cell height to 76px and vertically stretching/overlapping adjacent catalog cells.
