# BUG-010: Checkout CVV Accepts Alphabetical Input and Lacks Numeric Keypad

**Severity:** Medium — Input validation defect allowing arbitrary non-numeric strings in payment security code.
**Framework:** Appium / XCUITest / Maestro
**Element Identifier:** `checkout-cvv`, `checkout-submit`, `checkout-error`
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** No (Is blocked by BUG-011 on broken build)

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken / Fixed (Requires BUG-011 fix to reach checkout screen)
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Appium Python Client (pytest 8.4.2) / Xcode xcodebuild

### Steps to Reproduce
*(Note: Because BUG-011 makes 'Proceed to Checkout' a no-op on the initial broken build, test with BUG-011 fix applied or by navigating directly to the Checkout screen).*

1. Launch the app fresh on a clean simulator.
2. Log in with `demo@techshop.com` / `password123`.
3. Add Product 1 ($60) to cart (`add-p1`) and navigate to Checkout screen.
4. Fill valid customer details: `Jane`, `Doe`, `jane.doe@example.com`, `1234567890`, `1111222233334444`, `12/29`.
5. Tap on the CVV field (`checkout-cvv`).
6. Observe the keyboard type presented on screen.
7. Type non-numeric alphabetical characters `ABC`.
8. Tap "Place Order" (`checkout-submit`).

### Expected Result
1. Tapping `checkout-cvv` summons a dedicated numeric keypad (`.keyboardType(.numberPad)` / `keyboardType="numeric"`).
2. If non-3-digit or alphabetical input is submitted, the form is rejected with error "CVV must be 3 digits" (`checkout-error`).

### Actual Result
A full alphanumeric keyboard is displayed. Alphabetical characters `ABC` are accepted into the field and submitted without validation error.
