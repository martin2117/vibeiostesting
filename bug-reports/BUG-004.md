# BUG-004: Discount Calculation Divides by 1000 Instead of 100

**Severity:** Medium — Financial/calculation defect causing promotional discount to calculate at 0.01% rather than 10%.
**Framework:** Maestro / Appium / XCUITest
**Element Identifier:** `discount-input`, `order-total`, `add-p1`
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** No

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Maestro v2.8.0 / pytest 8.4.2 / xcodebuild

### Steps to Reproduce
1. Launch the app fresh on a clean simulator.
2. Log in with `demo@techshop.com` / `password123`.
3. Add Product 1 (Wireless Headphones - $60.00) to the cart by tapping `add-p1`.
4. Navigate to the Cart tab.
5. Tap the discount code field (`discount-input`), enter `SAVE10`, and dismiss the keyboard.
6. Observe the calculated Order Total (`order-total`).

### Expected Result
Applying promo code `SAVE10` deducts a 10% discount ($6.00) from the $60.00 subtotal, updating `order-total` to display "Order Total: $54".

### Actual Result
`order-total` remains displayed as "Order Total: $60" because `10 / 1000` is computed ($0.006 off), which rounds to $0.00 deduction.
