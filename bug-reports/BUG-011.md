# BUG-011: Proceed to Checkout Button Is Unresponsive (BLOCKER)

**Severity:** Critical — Complete blocker preventing all users from reaching checkout and placing orders; blocks all downstream checkout test automation.
**Framework:** Maestro / Appium / XCUITest
**Element Identifier:** `proceed-checkout`
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** Yes — Blocks TC-CHK-001 through TC-CHK-010 (BUG-009, BUG-010, BUG-012, BUG-013, BUG-017)

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Maestro v2.8.0 / pytest 8.4.2 / xcodebuild

### Steps to Reproduce
1. Launch the app fresh on a clean simulator.
2. Log in with `demo@techshop.com` / `password123`.
3. Add Product 1 ($60) to the cart (`add-p1`).
4. Navigate to the Cart tab.
5. Tap the "Proceed to Checkout" button (`proceed-checkout`).

### Expected Result
Tapping `proceed-checkout` transitions the navigation stack to the Checkout screen (`checkout-firstName`, `checkout-submit`).

### Actual Result
The button is completely unresponsive (a no-op). The user remains stuck indefinitely on the Cart screen; no navigation event is triggered.
