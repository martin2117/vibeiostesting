# BUG-008: Out-of-Stock Status Badge Rendered in Green Instead of Red

**Severity:** Low — Visual/color presentation defect misleading customers into believing unavailable item is in stock.
**Framework:** Manual / Visual Inspection (Accessibility tree does not expose RGB pixel colors)
**Element Identifier:** `badge-p4`, `add-p4`
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** No

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Visual Inspection / Exploration

### Steps to Reproduce
1. Launch the app fresh on a clean simulator.
2. Log in with `demo@techshop.com` / `password123`.
3. Locate Product 4 (USB-C Hub) on the catalog screen.
4. Observe the status pill badge next to the product (`badge-p4`).

### Expected Result
The "Out of Stock" badge is styled in a prominent **red** color (RGB `#e74c3c` / `.foregroundColor(.red)`) to clearly signal item unavailability.

### Actual Result
The "Out of Stock" badge text is styled in **green** (RGB `#2ecc71` / `.foregroundColor(.green)`), which is the styling reserved for "In Stock" items.

### Evidence & Artifacts
- **Artifact Type:** Appium Screenshot / Simulator Snapshot
- **Artifact Path / Reference:** `test-results/appium-broken/test_tc_cat_002_truncate_long_product_titles_without_overflow.png`
- **Error Log / Trace:** Visual inspection confirms `.green` color token applied to `Text("Out of Stock")` in `CatalogView.swift`.
