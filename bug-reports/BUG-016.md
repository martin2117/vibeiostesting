# BUG-016: Log In Submit Button Lacks Accessibility Identifier

**Severity:** Low — Mobile testability and automation defect hindering stable UI testing.
**Framework:** Appium / XCUITest / Maestro
**Element Identifier:** `login-submit` (Defect: Identifier missing on button)
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** No (Workaround: test suites fallback to matching raw label "Log In")

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Appium Python Client / Xcode xcodebuild

### Steps to Reproduce
1. Launch the app fresh on a clean simulator.
2. Inspect the accessibility hierarchy of the "Log In" button on the Login screen.
3. Query the element using accessibility identifier `login-submit` (`el("login-submit")` / `app.buttons["login-submit"]`).

### Expected Result
The Log In button has a dedicated accessibility identifier: `.accessibilityIdentifier("login-submit")` (or `testID="login-submit"` in React Native).

### Actual Result
The element lacks an accessibility identifier and can only be located via localized text matching (`app.buttons["Log In"]`).
