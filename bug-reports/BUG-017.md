# BUG-017: Software Keyboard Obscures CVV Input Field and Checkout Action

**Severity:** High — Usability and interaction defect blocking checkout completion on smaller screens when keyboard is open.
**Framework:** Maestro / Appium / XCUITest
**Element Identifier:** `checkout-cvv`, `checkout-submit`
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** No (Is blocked by BUG-011 on broken build)

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken / Fixed (Requires BUG-011 fix to reach checkout screen)
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Maestro v2.8.0 / pytest 8.4.2 / xcodebuild

### Steps to Reproduce
*(Note: Because BUG-011 makes 'Proceed to Checkout' a no-op on the initial broken build, test with BUG-011 fix applied or by navigating directly to the Checkout screen).*

1. Launch the app fresh on a clean simulator.
2. Log in with `demo@techshop.com` / `password123`.
3. Add Product 1 ($60) to cart (`add-p1`) and navigate to the Checkout screen.
4. Fill Name, Email, Phone, Card Number, and Expiry fields.
5. Tap on the CVV input field (`checkout-cvv`) located near the bottom of the screen.
6. Observe the software keyboard presentation and screen scrolling behavior.

### Expected Result
The form content is wrapped in a `ScrollView` that automatically offsets its viewport, keeping `checkout-cvv` and the "Place Order" button (`checkout-submit`) fully visible and accessible above the keyboard.

### Actual Result
The form is hosted inside a fixed non-scrolling `VStack`. When the software keyboard appears, it slides over and permanently obscures the CVV field and "Place Order" button, with no ability to scroll down or tap submit while the keyboard is focused.
