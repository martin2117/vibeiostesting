# BUG-003: Login Form Accepts Incorrect Password and Unregistered Email

**Severity:** High — Critical security failure allowing unauthorized login with invalid credentials.
**Framework:** Maestro / Appium / XCUITest
**Element Identifier:** `login-email`, `login-password`, `login-error`, `login-submit` (or text: "Log In")
**Cross-Build Status:** Reproduces on both SwiftUI & React Native
**Blocks Other Tests:** No

### Environment
- **Build Type:** SwiftUI (`com.techshop.ios`) & React Native (Expo)
- **Build Variant:** Broken
- **iOS Version:** iOS 26.5
- **Simulator / Device:** iPhone 17 Pro Simulator
- **Framework & Runner:** Maestro v2.8.0 / pytest 8.4.2 / xcodebuild

### Steps to Reproduce
1. Launch the app fresh on a clean simulator.
2. Tap `login-email` and enter `demo@techshop.com`.
3. Tap `login-password` and enter `wrongpassword`.
4. Tap the "Log In" button.

### Expected Result
Login is rejected. The user remains on the Login screen, an error message "Invalid email or password" is displayed on `login-error`, and catalog navigation is blocked.

### Actual Result
No error message is displayed. The application authenticates and transitions to the Product Catalog.
